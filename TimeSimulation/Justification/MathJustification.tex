\section*{1. Описание модели}\mbox{}\\*

\subsection*{1.1 Сущности}\mbox{}\\*

Рассматриваемая схема метро состоит из ключевых сущностей:

\begin{itemize}
  \item \textbf{Станция} — $S$,
  \item \textbf{Переезд} — $R$,
  \item \textbf{Переход} — $T$.
\end{itemize}

Ветки не рассматриваются напрямую, их влияние косвенное.

\subsection*{1.2 Типы связей}\mbox{}\\*

Вычисления происходят между сущностями следующим образом:

\begin{table}[h]
\centering
\begin{tabular}{|c|c|c|c|}
\hline
Связь & Станция ($S_2$) & Переезд ($R_2$) & Переход ($T_2$) \\
\hline
Станция ($S_1$) & - & + & + \\
\hline
Переезд ($R_1$) & + & - & - \\
\hline
Переход ($T_1$) & + & - & - \\
\hline
\end{tabular}
\end{table}

Таким образом, необходимо рассчитать время для следующих типов переходов:

\begin{enumerate}
  \item $S \to R$,
  \item $R \to S$,
  \item $S \to T$,
  \item $T \to S$.
\end{enumerate}

\section*{2. Параметры}\mbox{}\\*

\subsection*{2.1 Локальные параметры}\mbox{}\\*

Локальные параметры задаются на этапе создания сущностей и остаются неизменными в рамках одной симуляции.

\subsubsection*{Параметры сущностей}\mbox{}\\*

\begin{enumerate}
\item \textbf{Станция (S)}:
  \begin{itemize}
    \item \texttt{Occupancy} — уровень загруженности станции;
  \end{itemize}
\item \textbf{Переезд (R)}:
  \begin{itemize}
    \item \texttt{Duration} — среднее время движения поезда по перегону;
  \end{itemize}
\item \textbf{Переход (T)}:
  \begin{itemize}  
    \item \texttt{Occupancy} — уровень загруженности перехода;
    \item \texttt{Duration} — среднее время движения пассажира по переходу при нулевой загруженности.
  \end{itemize}
\end{enumerate}

\section*{3. Вычисления}\mbox{}\\*

\subsection*{3.1 Локальные параметры}\mbox{}\\*

Пусть:

\begin{itemize}
  \item $S_i$ — $i$-я станция, где $i = 1, ..., S_N$, $S_N$ — количество станций,
  \item $R_j$ — $j$-й переезд, где $j = 1, ..., R_N$, $R_N$ — количество переездов,
  \item $T_k$ — $k$-й переход, где $k = 1, ..., T_N$, $T_N$ — количество переходов.
\end{itemize}

Тогда:

\begin{itemize}
  \item $\text{Socc}_i$ — загруженность $i$-й станции,
  \item $\text{Rdur}_j$ — среднее время поезда по $j$-му переезду,
  \item $\text{Tocc}_k$ — загруженность $k$-го перехода,
  \item $\text{Tdur}_k$ — среднее время движения по $k$-му переходу.
\end{itemize}

Все эти данные берутся из заготовленных таблиц.

\subsection*{3.2 Глобальные параметры}\mbox{}\\*

\subsubsection*{Произвольные константы}\mbox{}\\*

Задать вручную:

\begin{itemize}
  \item $\zeta$ --- \texttt{AverStationEntryTime},
  \item $\eta$ --- \texttt{AverStationExitTime},
  \item $\tau$ --- \texttt{AverTrainWaitTime},
  \item $\gamma$ --- \texttt{QuintileTrustLevel}.
\end{itemize}

\subsubsection*{Характеристические данные}\mbox{}\\*

\begin{itemize}
  \item \texttt{AverChartBranchesStationsOccupancy} или \texttt{acbsOcc} или $\mathcal{O}$:
    \begin{equation}
      \mathcal{O} = \frac{1}{R_N} \sum_{i=1}^{S_N} \text{Socc}_i
      \label{eq:characteristic:acbsOcc}
    \end{equation}
  \item \texttt{AverChartBranchesRailwaysDuration} или \texttt{acbrDur} или $\Upsilon$:
    \begin{equation}
      \Upsilon = \frac{1}{R_N} \sum_{j=1}^{R_N} \text{Rdur}_j
      \label{eq:characteristic:acbrDur}
    \end{equation}
  \item \texttt{AverBranchStationsOccupancy} или \texttt{absOcc} или $\mathrm{o}_b$:
    \begin{equation}
      \mathrm{o}_b = \frac{1}{N_b} \sum_{i}^{N_b} \text{Socc}_i
      \label{eq:characteristic:absOcc}
    \end{equation}
    для станций, принадлежащих $b$-ой ветке.
  \item \texttt{AverBranchRailwaysDuration} или \texttt{abrDur} или $\upsilon_b$:
    \begin{equation}
      \upsilon_b = \frac{1}{N_b} \sum_{j}^{N_b} \text{Rdur}_j
      \label{eq:characteristic:abrDur}
    \end{equation}
    для переездов, принадлежащих $b$-ой ветке.
\end{itemize}

\subsection*{3.3 Расчёт времени входа на станцию}\mbox{}\\*

Пассажир, перед началом следования маршруту, обязан очутиться на стации, потратив некоторое время на это.
Оно зависит от базового среднего времени входа, разброса времени входа со станции,
уровня загруженности станции и выбранного доверительного уровня.

Для симуляции выбирается \textbf{логнормальное распределение}.

\subsection*{Описание параметров:}\mbox{}\\*

\begin{itemize}
\item \texttt{occupancy} — уровень загруженности станции ($Socc$), целое число $[0, 10]$;
\item \texttt{zeta} ($\zeta$) — среднее время входа при нулевой загруженности (c.);
\item \texttt{rho} ($\rho$) — разброс времени входа (стандартное отклонение, c.);
\item \texttt{k} ($k$) — коэффициент влияния загруженности на среднее время;
\item \texttt{gamma} ($\gamma$) — доверительный уровень для квантили.
\end{itemize}

\subsection*{Формулы}\mbox{}\\*

Расчёт производится с учётом логнормального распределения времени входа,
чтобы учесть несимметричность реального поведения пассажиров.

\begin{enumerate}
\item Скорректированное среднее время входа:
  \begin{equation}
    \mu_{\text{вход}} = \zeta \cdot \left(1 + k \cdot \frac{\text{Socc}_i}{10} \right),
    \label{eq:station:entry:correctAver}
  \end{equation}

  где:

  \begin{itemize} 
    \item $\zeta = \texttt{AverStationEntryTime}$ — базовое время входа;
    \item $\text{Socc}_i$ — уровень загруженности $i$-й станции;
    \item $k$ — коэффициент влияния загрузки.
  \end{itemize}

\item Параметры логнормального распределения:
  \begin{equation}
    \sigma_{\ln} = \sqrt{\ln\left(1 + \left(\frac{\rho}{\mu_{\text{вход}}} \right)^2\right)},
    \label{eq:station:entry:correctSigmaLn}
  \end{equation}

  \begin{equation}
    \mu_{\ln} = \ln(\mu_{\text{поезд}}) - \frac{1}{2} \sigma_{\ln}^2.
    \label{eq:station:entry:correctAverLn}
  \end{equation}

  где:

  \begin{itemize}
    \item $\mu_{\text{вход}}$ из (\ref{eq:station:entry:correctAver}),
    \item $\rho$ — разброс времени входа (стандартное отклонение, c.).
  \end{itemize}

\item Квантиль нормального распределения уровня $\gamma$:
  \begin{equation}
    z_\gamma = \Phi^{-1}(\gamma)
    \label{eq:station:entry:quintile}
  \end{equation}

\item Итоговое время входа с уровнем уверенности $\gamma$:
  \begin{equation}
    T_{\text{вход}} = \mu_{\text{вход}} + z_\gamma \cdot \sigma
    \label{eq:station:entry:lastReplace}
  \end{equation}

\end{enumerate}

\subsection*{3.4 Расчёт времени выхода со станции}\mbox{}\\*

Пассажир, успешно преодалев маршрут, должен выйти на улицу со станции.
Для этого используется готовое решение по формулам (\ref{eq:station:entry:correctAver} -- \ref{eq:station:entry:lastReplace}).

\subsection*{3.5 Расчёт времени движения поезда по перегону}\mbox{}\\*

Поезда движутся между станциями в рамках одной ветки по переездам (перегонам).
Примем, что время, которое поезда тратят, чтобы перейти из состояния отправления
из стоячего положения из одной станции, в стоячее положение на следующей станции, зависит от
среднего времени движения по данному перегону, разброса времени (стандартного отклонения) для
перегонов, средней загруженности схемы метро, средней загруженности текущей ветки метро
и выбранного доверительного уровня.

Для симуляции выбирается \textbf{логнормальное распределение}.

\subsubsection*{Формулы}

\begin{enumerate}
\item Скорректированное среднее время поезда:
  \begin{equation}
    \mu_{\text{поезд}} = \text{Rdur}_j \cdot \left(1 + k_1 \cdot \frac{\mathcal{O}}{10} + k_2 \cdot \frac{o_b}{10} \right)
  \end{equation}

\item Параметры логнормального распределения:

  \begin{equation}
    \sigma_{\ln} = \sqrt{\ln\left(1 + \left(\frac{\rho_R}{\mu_{\text{поезд}}} \right)^2\right)},
  \end{equation}

  \begin{equation}
    \mu_{\ln} = \ln(\mu_{\text{поезд}}) - \frac{1}{2} \sigma_{\ln}^2,
  \end{equation}

\item Квантиль нормального распределения уровня $\gamma$:
  \begin{equation}
    z_\gamma = \Phi^{-1}(\gamma)
  \end{equation}

\item Итоговое время движения поезда:
  \begin{equation}
    T_{\text{поезд}} = e^{\mu_{\ln} + z_\gamma \cdot \sigma_{\ln}}
  \end{equation}

\end{enumerate}

\subsection*{3.6 Расчёт времени ожидания поезда на станции}\mbox{}\\*

Когда поезд достигает станции, он не отправляется немедленно —
пассажиры должны успеть выйти или войти в вагоны.
Это время зависит от следующих факторов:

\begin{itemize}
  \item \texttt{AverTrainWaitTime} ($\tau$) — среднее время ожидания поезда на станции;
  \item \texttt{DispersionTrainWaitTime} ($\epsilon$) — разброс (стандартное отклонение) времени ожидания;
  \item $\mathcal{O}_b$ (\texttt{AverBranchStationsOccupancy}) — средняя загруженность станций текущей ветки;
  \item $\text{Socc}_i$ — уровень загруженности текущей станции;
  \item $\gamma$ - уровень доверия.
\end{itemize}

Для симуляции выбирается \textbf{гамма-распределение}.

\subsubsection*{Формулы}

\begin{enumerate}
  \item Скорректированное среднее время ожидания:
    \begin{equation}
     \mu = \tau \cdot \left(1 + k_1 \cdot \frac{\mathcal{O}_b}{10} + k_2 \cdot \frac{\text{Socc}_i}{10} \right)
    \end{equation},
    где $k_1$, $k_2$ — коэффициенты влияния загрузки ветки и станции соответственно.

\item Параметры гамма-распределения:
$$
\text{shape} = \frac{\mu^2}{\epsilon^2}, \quad
\text{scale} = \frac{\epsilon^2}{\mu}
$$

\item Итоговое время ожидания на уровне уверенности $\gamma$ (квантиль гамма-распределения):
$$
T_{\text{ожид}} = \Gamma^{-1}(\gamma; \text{shape}, \text{scale})
$$
где $\Gamma^{-1}$ — обратная функция распределения гамма-закона.
\end{enumerate}

\subsection*{3.7 Расчёт времени движения пассажира со станции к переходу}\mbox{}\\*

Если пассажиру потребуется перейти на другую ветку, воспользовавшись переходом,
то ему придется потратить время, что дойти до этого перехода. Это время зависит
от следующих файторов:

\begin{itemize}
  \item \texttt{dur} - среднее время движения пассажира по станции до перехода (с.).
  \item \texttt{durD} - разброс среднего времени движения (с.).
  \item $\text{Socc}_i$ — уровень загруженности текущей станции;
  \item \texttt{Occupancy} — уровень загруженности перехода;
  \item $\gamma$ - уровень доверия.
\end{itemize}

Для симуляции выбирается \textbf{гамма-распределение}.

\subsubsection*{Формулы}

Вычисления будут аналогичны проделанным формулам в
главе "Расчёт времени ожидания поезда на станции" (3.6).

\subsection*{3.8 Расчёт времени движения пассажира по переходу}\mbox{}\\*

Пассажир передвигается по переходу... Это время зависит
от следующих файторов:

\begin{itemize}
  \item \texttt{dur} - среднее время движения пассажира по переходу (с.).
  \item \texttt{durD} - разброс среднего времени движения (с.).
  \item \texttt{Occupancy} — уровень загруженности перехода;
  \item $\gamma$ - уровень доверия.
\end{itemize}

Для симуляции выбирается \textbf{логнормальное распределение}.

\subsubsection*{Формулы}

Вычисление будет аналогичным проделанным формулам в
главах 3.3 --- 3.5.
