\chapter*{ЗАКЛЮЧЕНИЕ}
\addcontentsline{toc}{chapter}{ЗАКЛЮЧЕНИЕ}

Цель достигнута --- разработана база данных для хранения и обработки данных маркетплейса.

Были выполнены все задачи:
\begin{itemize}
	\item[---] проведен анализ существующих решений;
	\item[---] формализованы данные;
	\item[---] спроектирована схема базы данных и ограничения целостности;
	\item[---] спроектирована ролевая модель на уровне базы данных;
    \item[---] проведено сравнение времени выполнения запросов при наличии индекса в базе данных и без него;
    \item[---] проведено сравнение объема используемого дискового пространства при наличии индекса в базе данных и без него.
\end{itemize}
