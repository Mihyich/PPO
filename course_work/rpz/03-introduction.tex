\chapter*{ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}

Цель -- разработка базы данных для масштабируемого планирования и сохранения маршрутов в метрополитенах.

Для достижения цели поставлены следующие задачи:
\begin{itemize}
	\item[---] провести анализ существующих решений;
	\item[---] формализовать данные;
	\item[---] спроектировать схему базы данных и ограничения целостности;
	\item[---] спроектировать ролевую модель на уровне базы данных;
	\item[---] провести исследование зависимости времени выполнения запросов от наличия индекса в базе данных и без него;
    \item[---] провести исследование зависимости объема используемого дискового пространства от наличия индекса в базе данных и без него.
\end{itemize}

Разрабатываемая система должна обладать конкуретным преимуществом за счет встроенной поддержки управления
параметрами транспортной модели в реальном времени для поддержания актуального состояния маршрутной
ситуации для наиболее правдивых поисковых запросов.
