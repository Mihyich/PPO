\chapter*{ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}

Цель работы --- разработка базы данных для масштабируемого планирования и сохранения маршрутов в метрополитенах.

Для достижения цели поставлены следующие задачи:
\begin{itemize}
	\item[---] провести анализ существующих решений;
	\item[---] формализовать данные;
	\item[---] спроектировать схему базы данных и ограничения целостности;
	\item[---] спроектировать ролевую модель на уровне базы данных;
	\item[---] сравнить время выполнения запросов при наличии индекса в базе данных и без него;
    \item[---] сравнить объем используемого дискового пространства при наличии индекса в базе данных и без него.
\end{itemize}
